# Task Collab

## Descripción

Task Collab es una plataforma web orientada a la gestión de tareas y colaboración en tiempo real para pequeños equipos de trabajo. El objetivo del proyecto es facilitar la organización de actividades, la asignación de responsabilidades y el seguimiento del progreso de los proyectos mediante una interfaz intuitiva y accesible.

Este proyecto es desarrollado como trabajo académico aplicando metodologías ágiles, específicamente Scrum, junto con herramientas de gestión como Jira para la planificación y seguimiento de tareas.

---

## Objetivos

* Facilitar la gestión de proyectos colaborativos.
* Permitir la creación y organización de tareas.
* Gestionar equipos de trabajo y roles de usuario.
* Mejorar el seguimiento del progreso de las actividades.
* Aplicar buenas prácticas de desarrollo de software y metodologías ágiles.

---

## Funcionalidades previstas

### Gestión de usuarios

* Registro de usuarios.
* Inicio de sesión.
* Gestión de roles y permisos.

### Gestión de proyectos

* Creación de proyectos.
* Administración de integrantes.
* Organización de equipos de trabajo.

### Gestión de tareas

* Crear tareas.
* Editar tareas.
* Marcar tareas como completadas.
* Eliminar tareas.
* Visualizar el estado de avance.

### Colaboración

* Asignación de responsabilidades.
* Seguimiento de actividades.
* Organización del trabajo en equipo.

## Estructura de ramas

* **main** → versión estable del proyecto.
* **develop** → integración de funcionalidades en desarrollo.
* **feature/*** → desarrollo de funcionalidades específicas.

Ejemplos:

* feature-login
* feature-proyectos
* feature-tareas
* feature-usuarios
